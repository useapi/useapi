### useapi.net: REST APIs for AI services, on your own accounts

[useapi.net](https://useapi.net/?utm_source=github.com&utm_medium=referral&utm_campaign=profile) is a third-party API for AI generation services that have no public API, or whose API costs far more than the website. You connect your own accounts, and one flat subscription covers every API below. There is no per-generation charge from us.

#### Example code

| Repository | What it covers |
|---|---|
| [google-flow-api](https://github.com/useapi/google-flow-api) | Google Flow: Veo 3.1 and Omni 1.1 Flash video, Nano Banana images, n8n templates (Node.js, Python) |
| [notebooklm-api](https://github.com/useapi/notebooklm-api) | NotebookLM (Gemini Notebook): web pages, PDFs and YouTube videos into podcasts and video overviews. Colab notebook, n8n workflows, an agent skill |
| [dreamina-api](https://github.com/useapi/dreamina-api) | Dreamina (CapCut): Seedance video, Seedream images |
| [flowmusic-api](https://github.com/useapi/flowmusic-api) | Google Flow Music: full songs with Lyria 3.5 and Lyria 3 Pro |
| [mureka-api](https://github.com/useapi/mureka-api) | Mureka: songs from lyrics or a description |
| [kling-api](https://github.com/useapi/kling-api) | Kling: text-to-video, Omni, motion control, lip-sync |
| [pixverse-api](https://github.com/useapi/pixverse-api) | PixVerse video |
| [minimax-api](https://github.com/useapi/minimax-api) | MiniMax (Hailuo): video and text-to-speech |
| [runway-api](https://github.com/useapi/runway-api) | Runway: video and Frames images |

Comparisons: [seedance-2-api](https://github.com/useapi/seedance-2-api) (one Seedance 2.0 job through four services, with a price dataset), [sora-2-alternatives](https://github.com/useapi/sora-2-alternatives), [ai-music-comparison](https://github.com/useapi/ai-music-comparison).

Tools: [google-account-setup](https://github.com/useapi/google-account-setup) (a clean, single-use Google sign-in for exporting session cookies, with device-bound sessions switched off; Windows, macOS, Linux).
